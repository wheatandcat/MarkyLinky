MarkyLinky 共有登録

このアプリをホーム画面に追加すると、他のアプリの共有メニューから MarkyLinky に URL を登録できるようになります。

このページは Android の Chrome でのみ利用できます。

Brave など Chrome 以外のブラウザや、Android 以外の端末では 「アプリをインストール」しても共有シートに登録されず、この機能は動作しません。 お手数ですが、Android 端末の Chrome でこのページを開き直してください。

まずアプリをインストールしてください。

ブラウザのタブで開いたままでは利用できません。「アプリをインストール」でホーム画面に追加し、追加されたアイコンから起動し直してください。

MarkyLinky 拡張機能のオプション画面で発行した API キーを貼り付けて保存してください。
